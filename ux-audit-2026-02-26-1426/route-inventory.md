## Legend

- `Status`: values from `migration-governance.md`
- `Current UI` (determined from the component each route record imports, not only from `meta.uiVersion`)
  - `V1`: route renders old UI layer (V1 view, no `uiVersion: 'v2'` meta, rendered in `AppV1Layout`)
  - `V2`: route renders new UI layer (imports a view from a `*-v2` directory built from V2 components)
  - `V2_partial`: route family has mixed V2 and V1 children
  - `V1_in_V2_shell`: route is tagged `meta.uiVersion: 'v2'` (so it renders inside the V2 shell, `AppV2Layout` / `GuestV2Layout`) but imports a V1 view. Passes the migration guard, but the page content is not migrated
- `Complexity`: S, M, L, XL (new families sized from the line count of their view files plus the feature components they mount)
- `Risk`: low, medium, high
- `Pencil Frames`: `none (no Pencil frame)` means `new-design.pen` has no frame for the family. These families follow "Families without Pencil frames" in `migration-governance.md`
